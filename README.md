# 알고케어 유저 후기 TV

사무실 TV에 고객 후기 멘트를 롤링으로 띄우는 페이지입니다. `docs/`가 GitHub Pages로 배포됩니다.

## 후기 추가·수정
1. `data/reviews.json`에 후기를 추가합니다. 후기 하나에 좋은 멘트를 0~5개 넣습니다(좋은 멘트가 없으면 비워도 됩니다).
2. `python3 build.py`를 실행합니다. 멘트 50개를 넘으면 가장 오래된 후기부터 빠집니다.
3. 커밋하고 푸시하면 TV 화면에 6시간 안에 반영됩니다.

필요한 패키지: `pip3 install segno`
